# World and Me Intelligence Map — Baseline Audit

## Existing capability

- The graph projects countries, companies, universities, evidence, and their typed relationships.
- Mission, evidence, and all-context focus modes use the existing graph builder.
- Keyboard navigation, entity selection, relationship explanation, and structured fallback remain available.
- “My World” data is consent-based and work-card creation requires confirmation.

## Truth boundary

- Registry and catalog relationships are not presented as live intelligence.
- When no verified live source exists, the interface says so instead of simulating activity.
- Missing, partial, and disputed context remain visible.
- CBAI explains relationships and change; the human decides whether to connect them to active work.

## Interface baseline

The shared Intelligence OS frame provides one status rail for context, evidence, unknowns, and the human checkpoint. Advanced graph engines remain progressively disclosed so the main canvas and the selected object stay primary.
