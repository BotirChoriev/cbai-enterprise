# Live Collaboration Rooms — Design Decisions

1. Preserve the existing room wizard, session model, consent flow, and voice controls.
2. Use one page entry surface instead of stacking a decorative hero above the functional room header.
3. Keep the primary action visible: open a collaboration room.
4. Show missing participants, materials, transport, and delivery capability as unknown or unavailable.
5. Keep evidence, objections, and decisions in the same room context.
6. Require explicit human confirmation before room creation and before any decision is recorded.
7. Keep Voice Operator available as an operating-system capability without allowing it to bypass confirmation.
